# Repositório de processos

Este repositório organiza processos em diretórios próprios. Cada processo mantém:

- `processo.md`: documentação, participantes e regras de negócio;
- `processo.bpmn`: modelo editável em BPMN 2.0 XML (fonte principal do diagrama);
- `processo.svg`: pré-visualização esquemática para consulta rápida.
